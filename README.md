# 🎯 QuizMagic Answer Fetcher — v1.4.0

- Compact redesigned extension popup.
- Small GitHub icon at the top-right linked to `https://github.com/Jalalkhan96`.
- Updated QuizMagic logo/icon assets.
- No floating button or bottom answer popup is injected into the QuizMagic page.
- Scroll position is saved per quiz session. Close the extension after reaching Q10 (or any question) and reopen it to resume at the same position.
- **Top** resets the popup view to the beginning.

## Install

1. Unzip the extension.
2. Open `chrome://extensions`.
3. Enable Developer mode.
4. Click **Load unpacked** and select the extracted folder.
